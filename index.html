Codex Run

Codex Run is een persoonlijk dashboard voor activiteit, slaap en herstel. Het draait op de eigen Mac; de dashboardtoegang is privé.

Een Google Health-koppeling leest na toestemming activiteit-, slaap- en gezondheidsmetingen. Deze website bevat alleen productinformatie en geen dashboard, gezondheidsgegevens of aanmeldgegevens.
